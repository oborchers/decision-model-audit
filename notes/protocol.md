# Protocol v1 (pre-registration)

Frozen before any model is called on evaluation data. Changes after the pilot are recorded in the changelog at the end with date and reason. Technical smoke tests on toy inputs (one ticket example) were run before this protocol to confirm API mechanics; they are not evaluation data.

## 1. Research questions

- **Q1 Accuracy and calibration** on the shared decision contract (same input, same label schema, one typed answer).
- **Q2 Selective prediction:** error rate when a model decides alone on a fixed share of cases and defers the rest (risk–coverage). Primary automation metric.
- **Q3 Stability:** sensitivity to label wording, option order and question form (one choice question versus one yes/no question per label).
- **Q4 Long input:** does the decisive information survive at increasing length and position?
- **Q5 No fitting label:** behaviour when the correct answer is "none of these", with and without an explicit "none" option.
- **Q6 Rationale cost:** accuracy, cost and latency of an LLM that writes a rationale before the label versus label only.
- **Q7 Cost and latency** per 1,000 decisions.

No hypothesis is formulated as "model X wins". Results are reported per source, never pooled.

## 2. Data sources

All evaluation text is dated on or after **2026-09-01**, after every disclosed training cutoff (Claude Haiku 4.5: training data to July 2025; gpt-5.4-nano: knowledge cutoff 2025-08-31). Jev and Gemini 3.1 Flash-Lite do not disclose cutoffs; for them, freshness is not established and is stated as such.

### S1 arXiv primary category

- Label set (8): `cs.CL`, `cs.CV`, `cs.CR`, `cs.RO`, `cs.DB`, `cs.SE`, `cs.HC`, `cs.DC`. Chosen as distinct but realistically overlapping computer science areas; `cs.LG` and `cs.AI` excluded because they act as catch-all categories.
- Label: `arxiv:primary_category`, chosen by the author and subject to moderation before publication. Treated as an operational target ("predict the submitted primary category"), not as the true subject.
- Input: title and abstract.
- Items: first versions submitted between 2026-09-01 and the collection date. Stratified random sample, 50 per category, 400 total, seed 20260927.
- Ambiguity marker: an item is *ambiguous* if it is cross-listed into another category of the label set. Results are reported for all items and for the unambiguous subset.
- Supervised baseline training data: abstracts with primary category in the label set submitted in 2024, 400 per category, disjoint from evaluation.

### S2 Federal Register issuing agency

- Label set: 8 agencies chosen in the pilot from the most frequent agencies since 2026-09-01 with distinct mandates. Final list recorded in the changelog before the main run.
- Label: issuing agency as recorded by the Federal Register (first listed agency; items with several agencies excluded).
- Input: title and abstract. Explicit agency names, acronyms and sub-agency names are masked with `[AGENCY]`; the residual leakage rate after masking is measured and reported.
- Items: 50 per agency, 400 total, seed 20260927.
- Dropped entirely if the pilot shows that masking fails (>10% residual leakage) or abstracts are missing for more than half the documents.

### S3 Constructed probes (labels by construction)

- **P1 Calibration.** Stated-probability scenarios: an urn with *r* red and *b* blue balls, a raffle with *k* of *n* winning tickets, a fair die with a stated set of winning faces. True probability *p* ∈ {0.1, 0.2, …, 0.9}. 3 templates × 9 levels × 5 surface variants = 135 items. Asked as yes/no ("Is the drawn ball red?"). Metric: absolute error between reported probability and *p*.
- **P2 Minimal pairs.** Short customer messages where one phrase flips the correct routing label (e.g. "I want to cancel" versus "I do not want to cancel, only pause"). 40 pairs written from fixed templates with slot fillers. Metric: accuracy and pair consistency (both members correct).
- **P3 Long input.** A single decisive sentence (e.g. "Please cancel my subscription at the end of this month.") inserted into neutral filler made of Federal Register notices from unrelated agencies. Lengths ≈ 500, 2,000, 8,000 and 24,000 tokens; relative positions 5%, 50%, 95%; with and without the decisive sentence (label yes or no). 5 variants per cell = 120 items. Haiku 4.5 limited to ≤ 8,000 tokens for cost.
- **P4 No fitting label.** arXiv abstracts from 2026-09-01 onwards whose primary category is outside the S1 label set and outside computer science (`astro-ph.*`, `math.*`, `q-bio.*`, `econ.*`, `cond-mat.*`), 100 items, asked with the S1 label set. Two variants: forced choice, and choice with an added option `none` ("None of the listed categories fits").
- Templates are written by hand in this repository, never generated by a language model, to avoid self-preference effects. Template families are recorded per item so intervals can be clustered.

## 4. Shared decision contract

- Every system receives the same label names and the same label descriptions. For S1 these are the official arXiv category descriptions, abbreviated to one sentence each. For S2 the agency's official one-line mission.
- LLM prompt (label only): system message with task and label descriptions; user message with the text; JSON schema `{label: enum, confidence: number}`.
- LLM prompt (rationale variant, Q6): schema `{reasoning: string, label: enum, confidence: number}`, reasoning first, instructed to cite phrases from the text.
- Jev: `state` = text; one `choice` question whose `criteria` map label → description.
- Verbalized confidence is reported as what it is and is not treated as equivalent to a model probability.
- Invalid or missing answers count as errors and are reported separately.

## 5. Metrics and statistics

- Accuracy with Wilson 95% interval; macro-F1.
- Calibration: expected calibration error with 10 equal-mass bins and bootstrap interval; Brier score (multi-class); reliability diagram. ECE reported only where n ≥ 200 in the condition.
- Selective prediction: risk–coverage curve, area under it (AURC), and error rate at 80% coverage. Deferral uses each system's own confidence.
- Paired comparisons against Jev: McNemar exact test on discordant items, Holm correction across systems within a source. Paired bootstrap (10,000 resamples) for differences in accuracy and error at 80% coverage.
- Probes: intervals clustered by template family (cluster bootstrap).
- Stability (Q3): agreement rate between variants and change in accuracy; for Jev and the NLI baseline additionally ECE per question form.

## 6. Pilot

- 5 items per category from S1 (40), 5 per agency from S2 (40), and 20 probe items, run on every system.
- Purpose: validate parsing, costs, latency, masking, label mapping. Pilot items are excluded from the main sample.
- The main run starts only after the pilot costs are extrapolated and the projected total stays below USD 4.50, leaving a reserve of about USD 1.30 of the USD 5.80 balance.

## 7. Reproducibility

- All API responses cached by request hash (`.cache/`, not committed) and written to `results/raw/*.jsonl` (committed).
- Data builders, sampled item IDs and seeds committed. arXiv and Federal Register texts are public; item files are committed with source URLs.
- Random seed 20260927 for all sampling.
